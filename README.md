# Employee-Work-Stress
HR dashboard analyzing work stress across 200 employees. Tracks emotional stress, workload, work-life balance, and managerial support by department and gender using KPI cards, bar/area charts, and a ribbon chart. Built in Power BI with Power Query data cleaning and custom conditional formatting.

<b>HR Dashboard of Work Stress</b>

Analyzes workplace stress factors across a 200-employee dataset, breaking down emotional stress, workload, work environment, managerial support, and work-life balance by department and gender.

<b>Tools & process</b>:
Built in Power BI Desktop. Used Power Query to clean survey response data — handling missing values, standardizing department names, and converting rating scales to consistent numeric formats. Applied custom color themes (green/red gradient for stress severity), conditional formatting on bar charts, and a ribbon chart to visualize ranking shifts across stress categories.

<b>Key components</b>:

Gender split (130 male / 70 female) via icon-based KPI cards
Managerial Support and Work-Life Balance by Department (bar/area charts)
Avg Work Stress by Gender and by Department (bar charts)
Avg Workload by Department with 100% stacked reference
Ribbon chart ranking departments across five stress dimensions

<b>Purpose</b>: Gives HR a diagnostic view to identify which departments and stress factors need intervention first.
